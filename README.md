# プログラミング言語タグ辞典

言語名を入力すると、代表的なタグ/キーワードの

- 呼び方
- 意味
- 使い方
- 例

を一覧表示するシンプルなWebアプリです。

## 対応言語

- JavaScript
- Python
- Java
- C#
- HTML
- CSS
- SQL
- Go
- Rust

## 使い方

1. `index.html` をブラウザで開く
2. 言語名を入力（例: `python`, `js`, `html`）
3. `表示` ボタンを押す
4. 必要なら「タグ絞り込み」で検索する

## 補足

- このアプリでは、HTMLのようなタグ型言語だけでなく、一般的なプログラミング言語の主要キーワードも「タグ/キーワード」としてまとめています。
